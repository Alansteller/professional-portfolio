NEXSHALY STUDIO — INTERACTIVE WEBSITE
=====================================

Files:
- index.html
- style.css
- script.js
- assets/nexshaly-logo.png

HOW TO USE
1. Extract the ZIP.
2. Upload all four items/folders to your website repository, keeping the assets folder structure.
3. Commit changes to the main branch and wait for GitHub Pages to publish.
4. Open your website and hard refresh (Ctrl+F5).

FEATURES INCLUDED
- Your uploaded Nexshaly Studio logo in the header, hero and favicon
- Responsive dark neon cyan/blue/purple design
- Mobile navigation menu
- Interactive website idea generator
- WhatsApp enquiry buttons with prefilled text
- Demo project card linking to your Attingal Mobile Hub demo
- Service cards and three pricing packages
- Interactive FAQ accordion
- Contact form that prepares a WhatsApp message

IMPORTANT
The contact form does not store or send information to a server. It opens WhatsApp with a prefilled message; the visitor must press Send.
The idea generator is rule-based JavaScript, not an AI chatbot.
The displayed package prices are the starting prices you supplied. Domain, paid hosting, bookings, payments, databases, extra pages and maintenance may cost extra.
Keep the assets/nexshaly-logo.png path and folder name unchanged unless you update the HTML references.
